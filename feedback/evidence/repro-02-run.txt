4. Summary
============================================================================================
These four owner-parameterised functions exist on the ETH perp pool (selectors present in the implementation bytecode, section 1) and are
properly gated: in the emulation, cancelOrdersFor needs only the cancel grant, reduceOrdersFor only the reduce grant, amendOrderFor needs
place AND cancel, and cancelAllOrdersFor is not operator-grantable at all (margin-bank only). This is NOT a security issue: with
zero grants every grantable function denies. But they are absent from @somnia-chain/markets-sdk@0.32.1 and from the bot-kit, and neither
package's shipped documentation mentions them or the grant each requires, so an integrator following the documented surface cannot discover them.
Suggested fix: document them (including the grant each needs, and that amendOrderFor needs two) or expose wrappers in the SDK.
